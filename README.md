# Strata

A terrain painter for HD-2D maps in Unity.

Paint levels, ground, walls, edges and stairs in the Scene view, then bake to a plain prefab. The map does not need Strata to run.

## Setup

Unity 6 with URP. Copy this folder into `Assets/Strata`.

## Use

- `Tools > Strata > New Terrain` to start
- `Tools > Strata > Terrain Editor` to paint
- `Tools > Strata > Materials` for tile sets

Open `Examples/Strata Sandbox` to try it.
